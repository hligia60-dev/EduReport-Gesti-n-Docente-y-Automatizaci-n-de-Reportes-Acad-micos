01. Definición & Alcance

¿Qué es EduReport?

EduReport es una plataforma web especializada en la gestión docente, control escolar y generación automática de reportes e informes oficiales para el Nivel Secundario del sistema educativo.

Diseñado tomando como base directa los Registros de Grado Oficiales de la República Dominicana, EduReport unifica y digitaliza los dos ciclos fundamentales:

Primer Ciclo

Abarca 1.º, 2.º y 3.º de Secundaria. Seguimiento por competencias específicas, indicadores de logro y 4 períodos evaluativos (P1 a P4).

Segundo Ciclo

Abarca 4.º, 5.º y 6.º de Secundaria con modalidades Académica, Técnico-Profesional y en Artes, control de expedientes y actas de promoción.

Estandarización curricular, respaldo en base de datos relacional y emisión de documentos con validez institucional.

02. Impacto & Transformación

¿Qué problema resuelve EduReport?

Los centros educativos y docentes enfrentan diariamente cuellos de botella administrativos que restan tiempo valioso al proceso de enseñanza-aprendizaje.

Sobrecarga en Papel

Llenado manual de libros de registro físicos voluminosos, propenso a tachaduras, extravíos y deterioro con el paso de los años.

Solución EduReport: Expediente digitalizado y pase de lista en segundos desde cualquier dispositivo.
Ausentismo Silencioso

Estudiantes que acumulan faltas dispersas a lo largo del mes sin que el personal de orientación o la familia se entere oportunamente.

Solución EduReport: Detección inmediata a la 3.ª inasistencia con disparo automático de alerta preventiva.
Errores de Calificación

Cálculos manuales errados de promedios de períodos (P1 a P4), recuperaciones pedagógicas y notas finales de promoción.

Solución EduReport: Motor computacional automatizado bajo los criterios exactos del currículo oficial.
Retraso de Citaciones

Dificultad y burocracia para redactar e imprimir circulares, notificaciones a tutores y constancias de seguimiento escolar.

Solución EduReport: Generación instantánea de fichas oficiales listas para firma e impresión directa.

04. Flujo de Trabajo

¿Cómo funciona EduReport?

Un flujo pedagógico intuitivo estructurado en 4 etapas interconectadas que garantizan agilidad y precisión.

1
Configurar Ciclo & Matrícula

Estructuración de grados (1.º a 6.º de Secundaria) y secciones con código RNE de estudiantes, datos familiares y contactos de emergencia.

2
Registro Diario Ágil

Pase de lista con estados oficiales: P (Presente), T (Tardanza), A (Ausente) y E (Excusa médica/justificada).

3
Reglas de Negocio en Vivo

El motor computacional audita las inasistencias en tiempo real. Al detectarse la 3.ª falta, se dispara de inmediato una alerta roja.

4
Emisión Automatizada

Generación con un solo clic de la ficha oficial de citación a tutor, sábanas completas de calificaciones y boletines de seguimiento listos para PDF.

05. Módulos & Capacidades

Principales Funcionalidades

Diseñadas con rigurosidad para responder a las exigencias operativas diarias de la educación secundaria.

Pase de Lista Inteligente (P, T, A, E)

Registro diario de asistencia con los 4 estados normativos: Presente, Tardanza, Ausente y Excusa justificada, con recálculo automático de porcentajes de asistencia por período.

Motor de Alerta Temprana (3 Faltas)

Monitoreo continuo que identifica estudiantes al alcanzar 3 ausencias acumuladas, emitiendo avisos visuales prioritarios para la intervención pedagógica oportuna.

Evaluación por Competencias & P1-P4

Estructura completa de períodos evaluativos (P1, P2, P3 y P4) con ponderaciones por indicadores de logro y gestión de Recuperación Pedagógica (RP) para notas inferiores a 70 puntos.

Expediente Integral del Estudiante

Ficha completa con datos personales, número de RNE, fecha de nacimiento, condición inicial (Nuevo / Repitente), datos del tutor y teléfonos de emergencia.

Reportes Oficiales & Soporte PDF

Plantillas formateadas listas para impresión y descarga en PDF: fichas de seguimiento con espacios de firma institucional, sábanas de curso y actas consolidadas.

Panel Analítico con Gráficos

Métricas en tiempo real visualizadas mediante Chart.js: distribución de matrícula por ciclo, índice de ausentismo por sección y estudiantes en estado de alerta.

06. Stack Tecnológico

Tecnologías Utilizadas

Arquitectura construida sobre un stack moderno, confiable, sin dependencias superfluas y de alto rendimiento.

Python 3.12+
Lenguaje Core

Núcleo backend que proporciona un desarrollo limpio, tipado robusto, procesamiento ágil de reglas y compatibilidad multiplataforma garantizada.

Framework Web

Microframework web configurado mediante el patrón Application Factory y Blueprints modulares para un enrutamiento ordenado y desacoplado.

SQLAlchemy & SQLite
Persistencia & ORM

Capa ORM potente con migraciones automáticas y base de datos relacional ligera, autocontenida y sin necesidad de instalar servidores externos pesados.

Bootstrap 5.3 + Icons
Frontend & CSS

Sistema de grilla 100% responsivo para móviles, tablets y monitores, complementado con tipografías Google Fonts y estilos CSS variables personalizados.

Chart.js
Data Visualization

Biblioteca JavaScript para renderizar gráficos de barras y de dona en el panel de control, facilitando el análisis visual inmediato de asistencia.

Jinja2 & HTML5 Semántico
Motor de Plantillas

Herencia de plantillas modular con layouts reutilizables, bloques dinámicos y formatos de impresión adaptados a documentos escolares normativos.

07. Diseño Técnico

Arquitectura del Sistema

Estructurado bajo el principio de Arquitectura en Capas Desacopladas (Layered Architecture), garantizando mantenibilidad, separación de responsabilidades y escalabilidad.

Capa de Presentación (Controladores & Vistas)

Maneja las solicitudes HTTP, renderiza las plantillas Jinja2 y expone endpoints JSON. Organizada en Blueprints modulares:

main_bp (Landing & Dashboard) student_bp (Estudiantes) attendance_bp (Asistencias & Alertas) report_bp (Generación de PDF/Impresión)
Capa de Servicios (Lógica de Negocio Pura)

Encapsula las reglas pedagógicas independientes de la capa web. Aquí reside la detección de la regla de 3 ausencias, cálculo de promedios de períodos y validación de matrículas:

attendance_service.py student_service.py evaluation_service.py
Capa de Persistencia & Datos (Modelos SQLAlchemy)

Define el esquema relacional íntegro con claves primarias, foráneas e índices optimizados almacenados en SQLite:

Student Cycle (1.º y 2.º) GradeLevel (1.º a 6.º) Section (A, B) Attendance (P, T, A, E) Evaluation (P1 a P4)

08. Organización de Código

Estructura del Proyecto

Diseño de directorios profesional, modular y estandarizado conforme a las mejores prácticas de la comunidad Python.

EduReport/ - Árbol del Proyecto 
EduReport/
├── app/                          # Paquete principal de la aplicación
│   ├── __init__.py               # Application Factory (create_app)
│   ├── config.py                 # Configuraciones (Dev, Test, Prod)
│   ├── models/                   # Entidades ORM SQLAlchemy
│   │   ├── academic.py           # Student, Cycle, GradeLevel, Section
│   │   ├── attendance.py         # Attendance (P, T, A, E)
│   │   └── evaluation.py         # Evaluation, Period, Recuperación
│   ├── routes/                   # Blueprints modulares Flask
│   │   ├── main_routes.py        # Landing, Dashboard, Entorno, Arquitectura
│   │   ├── student_routes.py     # CRUD y listado de matrícula
│   │   ├── attendance_routes.py  # Pase de lista y panel de 3 faltas
│   │   └── report_routes.py      # Sábanas de notas e informes PDF
│   ├── services/                 # Lógica de negocio y reglas
│   │   ├── attendance_service.py # Regla preventiva de 3 ausencias
│   │   └── student_service.py    # Consultas y agregados de estudiantes
│   ├── static/                   # Recursos web del cliente
│   │   ├── css/ style.css        # Hoja de estilos moderna y tokens
│   │   └── js/  main.js          # Simulador interactivo y utilidades
│   └── templates/                # Plantillas Jinja2 responsivas
│       ├── base.html             # Layout maestro institucional
│       ├── index.html            # Landing page pública
│       └── dashboard.html        # Panel estadístico con Chart.js
├── database/                     # Scripts de inicialización y semillas
├── docs/                         # Documentación técnica y diagramas
├── instance/                     # Base de datos SQLite local
├── run.py                        # Punto de arranque del servidor
└── requirements.txt              # Dependencias oficiales de Python
Fábrica de Aplicaciones (app/__init__.py)

Inicializa extensiones (SQLAlchemy), registra Blueprints de forma desacoplada e inicializa automáticamente la base de datos si es la primera ejecución.

Servicios Aislados (app/services/)

Evita la concentración de lógica en las rutas, facilitando pruebas unitarias y manteniendo la integridad de las reglas escolares.

Modularidad de Rutas (app/routes/)

Cada área funcional del centro (asistencia, calificaciones, matrícula, reportes) posee su propio archivo de rutas dedicado.

09. Despliegue Rápido

Cómo Ejecutar el Proyecto

Sigue estos sencillos pasos para levantar EduReport localmente en cualquier entorno (Windows, macOS o Linux).

1
Crear el Entorno Virtual

Aísla las dependencias del proyecto en una carpeta dedicada:

python -m venv .venv
2
Activar el Entorno Virtual

En Windows PowerShell o CMD:

.\.venv\Scripts\activate (En Linux/Mac: source .venv/bin/activate)
3
Instalar Dependencias

Descarga Flask, SQLAlchemy y las librerías necesarias:

pip install -r requirements.txt
4
Lanzar el Servidor Flask

La app autosemilla datos de prueba en la primera ejecución:

python run.py
Abre tu navegador en: http://127.0.0.1:5000
Entrar al sistema ahora
